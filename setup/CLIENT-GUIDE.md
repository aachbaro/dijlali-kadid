# Guide Client - Utilisation Simple

Ce guide est destine a une personne non technique. L'objectif est d'utiliser le site sans avoir a comprendre WordPress.

## Connexion

Adresse :

```text
/wp-admin
```

Apres connexion, commencer par le menu :

```text
Mode Client
```

Compte local de test :

```text
client
client123
```

En production, ce mot de passe doit etre remplace avant livraison.

## Actions Du Quotidien

### Ajouter une oeuvre

1. Cliquer sur `Mode Client > Ajouter une oeuvre`.
2. Renseigner le titre de l'oeuvre.
3. Ajouter la photo principale.
4. Renseigner le prix.
5. Choisir le statut : `Disponible`, `Reservee` ou `Vendue`.
6. Ajouter la description : technique, dimensions, annee, histoire.
7. Publier.
8. Ouvrir la fiche sur le site pour verifier.

Note : l'ecran `Mode Client > Ajouter une oeuvre` remplit WooCommerce automatiquement. Il n'est pas necessaire d'aller dans les reglages avances WooCommerce.

### Marquer une oeuvre comme vendue

1. Aller dans `Mode Client > Mes oeuvres`.
2. Cliquer sur `Marquer vendue`.

### Supprimer une oeuvre

1. Aller dans `Mode Client > Mes oeuvres`.
2. Cliquer sur `Supprimer`.
3. Confirmer.

Note : l'oeuvre est placee dans la corbeille. Elle n'est pas supprimee definitivement depuis cette interface.

### Ajouter un article de blog

1. Cliquer sur `Mode Client > Ajouter un article`.
2. Ajouter une image principale si possible.
3. Renseigner le titre.
4. Choisir une categorie.
5. Ajouter un resume court.
6. Ajouter le texte complet.
7. Enregistrer en brouillon ou publier.
8. Ouvrir l'article sur le site pour verifier.

### Modifier ou supprimer un article

1. Aller dans `Mode Client > Mes articles`.
2. Cliquer sur `Modifier` pour corriger le texte.
3. Cliquer sur `Supprimer` pour placer l'article dans la corbeille.

Note : comme pour les oeuvres, la suppression passe par la corbeille.

### Ajouter une prestation

1. Cliquer sur `Mode Client > Ajouter une prestation`.
2. Ajouter une image si possible.
3. Renseigner le titre.
4. Renseigner le prix.
5. Ajouter la duree, le format, le public et le mode de reservation.
6. Ajouter le resume court et la description complete.
7. Enregistrer en brouillon ou publier.
8. Ouvrir la fiche sur le site pour verifier.

### Modifier ou supprimer une prestation

1. Aller dans `Mode Client > Mes prestations`.
2. Cliquer sur `Modifier` pour changer le tarif, la duree ou le texte.
3. Cliquer sur `Supprimer` pour placer la prestation dans la corbeille.

### Voir une commande

1. Aller dans `Mode Client > Commandes`.
2. Ouvrir la commande.
3. Verifier le paiement, l'adresse et les articles.
4. Preparer l'envoi ou le retrait.
5. Une fois termine, passer la commande en `Terminee`.

### Gerer une reservation

1. Aller dans `Mode Client > Reservations Amelia`.
2. Verifier les rendez-vous a venir.
3. Modifier uniquement les horaires, services et disponibilites valides.

### Messages de contact

Les messages du formulaire arrivent par email. La page Contact sert surtout a modifier le texte public.

## A Ne Pas Toucher Sans Aide

- Extensions
- Theme
- Reglages techniques
- Stripe
- WooCommerce > Reglages
- Polylang
- Rank Math
- WP Mail SMTP
- Wordfence

## Formation Recommandee

Prevoir une formation de 1h a 2h avec la cliente :

1. Se connecter.
2. Ajouter une oeuvre test.
3. Modifier une oeuvre.
4. Ajouter un article test.
5. Ajouter une prestation test.
6. Lire une commande.
7. Voir une reservation.
8. Modifier une page simple.
9. Se deconnecter.

Finir la formation avec une fiche papier ou PDF reprenant seulement ces actions.
